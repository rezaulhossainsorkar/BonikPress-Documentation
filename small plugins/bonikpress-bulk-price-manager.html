03
Core purpose

Manage pricing at scale.

The core problem is simple: editing WooCommerce product prices one product at a time does not scale well. Bulk Price Manager provides a structured interface for selecting products, inspecting them, and applying pricing operations in bulk.

1
SELECT

Find the right products

Use product filters to narrow the working set before performing a pricing operation.

2
CALCULATE

Apply pricing rules

The pricing engine is intended to support configurable calculations instead of simple blind value replacement.

3
UPDATE

Change prices in bulk

Apply the resulting pricing operation across the selected WooCommerce products.

function bpm_get_products( $filters = array() ) {
    $args = bpm_build_product_query_args( $filters );
    return wc_get_products( $args );
}

08
Architecture philosophy

Simple by design.

Bulk Price Manager is being built as a learning-friendly, maintainable WordPress plugin rather than an unnecessarily abstract framework.

P

Procedural PHP

The project intentionally uses procedural PHP and straightforward WordPress patterns.

W

WordPress standards

Follow WordPress Coding Standards and use native WordPress/WooCommerce APIs where appropriate.

M

Incremental design

Features are introduced one layer at a time, prioritizing clarity and maintainability over cleverness.

The architecture should become more sophisticated only when the product genuinely requires it — not simply because a more complex pattern is available.
